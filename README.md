# 个人信贷违约预测 · Give Me Some Credit

用同一套交叉验证口径，从逻辑回归 baseline 走到 LightGBM 与模型融合，并给出业务阈值下的通过率与坏账率——而不只是 AUC。

> **状态**：W1（2026-11-09 起）· 数据与环境已就绪，建模进行中

## 1. 业务背景

*（待补：谁用这个模型、决策是什么、错了的代价怎么量化）*

信贷审批中的两类错误代价不对称：

- **拒真**（拒绝了会按时还款的好客户）：损失利息收入与客户终身价值
- **拒假**（给会违约的客户放款）：损失本金

所以评估不能停在 AUC —— 必须给出「在 X% 通过率下，坏账率是多少」，业务方才能判断模型值不值得上线。

## 运行方式

依赖已装在项目内的隔离虚拟环境 `.venv` 中，不影响系统 Python：

```bash
# 数据初探
.venv/Scripts/python.exe src/peek_data.py
```

如需重建环境：

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
```
